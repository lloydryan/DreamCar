# Dream 911

A scroll-driven Porsche 911 GT3 funding page built with Next.js, React, and Tailwind CSS.

## Run locally

```bash
npm ci
npm run dev
```

Open `http://localhost:3000`.

## Deploy to Vercel

1. Push this project, including the `public/` image files, to a Git repository.
2. In Vercel, choose **Add New Project** and import the repository.
3. Keep the detected **Next.js** framework preset and the default build command: `npm run build`.
4. Deploy.

No environment variables are required. All showroom and rotation images are served from `public/`.
